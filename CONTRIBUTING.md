# Contributing

Thank you for looking. Blyg for Obsidian is a one-person beta, so a few plain rules keep this manageable.

- **Issues are very welcome.** Use the issue forms: a bug report (what you did, what you saw, your versions) or a feature request. Never include a token, a password or the text of private notes.
- **Pull requests from outside are not being accepted for now.** A pull request that arrives may be closed with a pointer back to an issue; that is not a judgement of the idea. If you want to work on something, open an issue first and say so.
- **Security problems:** do not open a public issue. Follow `SECURITY.md` (GitHub's private vulnerability reporting).
- **How the code is developed** (invariants, checks, the leak scan that runs on every push): `AGENTS.md`. Parts of it are written with the help of AI coding agents; commits and pull requests say so.
- **Licence:** MIT. By contributing you agree your contribution is under it.
